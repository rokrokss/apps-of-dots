STEP 01 / DISCORD

Meet your Discord bot.

Your bot connects the servers you choose to your dot.

Get your bot ready
  1. Open the Discord Developer Portal ↗ and create or choose an application.
  2. In Bot, get its token and enable Message Content and Server Members intents.
  3. Invite the bot to your server with the permissions you want it to have.
Bot permissions & setup guide ↗

Stored privately on this computer. It won’t be shown again.

Choose specific servers Optional

Use all, or comma-separated server IDs. The bot’s Discord permissions still apply.

STEP 01 / TELEGRAM

Your Telegram, connected.

First, get your account’s API credentials. Then we’ll show a QR code to scan on your phone.

Get your API ID and hash
  1. Sign in at my.telegram.org ↗.
  2. Open API development tools and create an application.
  3. Copy its api_id and api_hash into the fields below.

You’ll also need Telegram on your phone. If two-step verification is enabled, we’ll ask for that password after you scan.

Saved privately on this computer. Leave blank to reuse a saved hash.

STEP 01 / WHATSAPP

Link your phone.

Link this computer to WhatsApp. There’s no developer token to create.

Keep your phone nearby
  1. Open WhatsApp on your phone.
  2. Go to Settings → Linked devices → Link a device. On Android, Linked devices is in the menu.
  3. After the tunnel settings, scan the QR code we show here and approve linking.

This computer will appear as a linked device. You can unlink it from your phone later.

Local bridge port Optional

Change this only if another app already uses this port.

The first setup needs uv, Go 1.26+ and a C compiler. Installation help ↗

STEP 02 / PRIVATE TUNNEL

A path to your AI.

Connect this app through your own OpenAI tunnel.

Create a tunnel for Discord
  1. Open OpenAI tunnel settings ↗ and create a tunnel.
  2. Associate it with the ChatGPT workspace you’ll use, then copy its ID.
  3. Create a runtime API key with Tunnels Read + Use. Creating the tunnel also needs Manage.

Use a separate tunnel for each app. Your ChatGPT workspace must also allow custom MCP servers.

Tunnel permissions & help ↗

Your key is saved locally and never returned to this page.

We’ll verify the bot, save your settings, and start the tunnel.

STEP 04 / USE WITH AI

One last connection.

Your tunnel is ready. Now add Discord to ChatGPT.

YOUR DISCORD TUNNEL
  1. Open ChatGPT Plugins ↗, then choose + → Add custom MCP server.
  2. Choose Tunnel and select or paste the ID above. For this private connection, use No authentication.
  3. Create and install the plugin, then select it in a chat.
TRY YOUR FIRST QUESTION

“Show me my Discord servers and their channels.”

Tunnel readiness doesn’t confirm a successful tool call. Try the question above to check permissions and finish setup.
