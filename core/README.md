# core

Shared code behind the `apps-of-dots` command. App integrations live at the repository root.

| Directory   | Contents                                                      |
| ----------- | ------------------------------------------------------------- |
| `src/`      | CLI commands, integration catalog, and the local setup center |
| `packages/` | Shared runtime and managed-MCP libraries used by every app    |
| `test/`     | CLI, setup center, and cross-app tests; frozen tool contracts |
| `scripts/`  | Build helpers                                                 |
| `docs/`     | [Architecture](docs/architecture.md)                          |
